# Changelog

## 0.1.0

- Sidebar with **Suggested Now**, **Frequently Used** and **All Skills** views.
- Skill discovery from the workspace, `~/.claude` and enabled Claude Code plugins.
- Per-workspace usage stats and recent arguments read from Claude Code history.
- Context-aware suggestions (open file, folder, branch, uncommitted changes) plus team rules in `.claude/skill-launcher.json`.
- One-click run into a Claude terminal, with argument prompt and new-session fallback.
- Skill detail panel and optional "Ask Claude" fit check / task-to-skill finder.
